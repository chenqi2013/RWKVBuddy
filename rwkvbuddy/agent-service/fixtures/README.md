# 内置分析样例

三家公司经营台账与一份集团资金流水，来自本机 foreman-cli 的核心测试样例。
金额为示例数据，不代表真实企业。

样例口径：收入 = sales + service；成本 = cogs + opex；
税后利润 = (收入 - 成本) × (1 - 税率)。interest 不纳入该示例口径。
资金只统计 status=posted 的记录。

期望结果：北辰科技 450,500.00；江南制造 341,250.00；西岭能源 278,400.00；
三家利润合计 1,070,150.00；资金净流入 56,900.25。

`shared/tax_rates.tsv` 同时支持真实制表符与此参考样例中的字面量 `\t` 分隔符。
